# Preliminary name screen

Status: **not trademark-cleared**. This is an engineering/product risk screen,
not legal advice or a substitute for a qualified trademark search.

## August 2, 2026 findings

- The exact lowercase npm package name `mpai` returned no package, and Homebrew
  returned no exact formula or cask. The distributed package remains
  `multiplayer-ai`; `mpai` is its CLI and public-alpha product shorthand.
- GitHub contains small unrelated repositories using the same acronym. None of
  the results reviewed presented the same terminal multiplayer product.
- A material adjacent use does exist: the international MPAI community expands
  the acronym as “Moving Picture, Audio and Data Coding by Artificial
  Intelligence,” says it was established in 2020, and publishes AI framework
  and data-coding standards. IEEE has adopted multiple specifications under the
  IEEE/MPAI name.

Primary references:

- https://mpai.community/about/
- https://mpai.community/standards/foreword
- https://sagroups.ieee.org/aifwg/

## Alpha decision

Keep the lowercase `mpai` CLI shorthand for the current public alpha, always
pair it with the descriptive line “multiplayer for Codex and Claude Code,” and
retain `multiplayer-ai` as the package/repository identity. Do not claim an
exclusive mark, file a trademark application, or build a hosted organization
control plane under this name based on this screen alone.

## Clearance gate

Before a paid hosted product, company-wide deployment, or trademark filing:

1. Have qualified counsel search exact and confusingly similar marks and
   common-law uses in the intended jurisdictions, especially software and SaaS
   classes.
2. Review USPTO, WIPO, EUIPO, company-name, domain, package-registry, app-store,
   and relevant open-source results—not only exact-string web results.
3. Assess the adjacent MPAI standards use for likely confusion across audience,
   channels, services, and geography.
4. Make an explicit rename/coexistence/filing decision before investing further
   brand equity.

Until those steps are complete, the trademark point in the launch-readiness
score remains open.
