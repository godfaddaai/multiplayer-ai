# Code of conduct

## Our standard

We want mpai to be a focused, generous place to build. Participants are
expected to:

- be respectful, specific, and constructive;
- critique ideas and code rather than people;
- welcome contributors with different experience levels and backgrounds;
- protect other people's private data and security;
- accept responsibility, apologize, and repair harm when mistakes happen.

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate exposure of credentials or transcripts, and sustained disruption
are not acceptable.

## Scope

This standard applies in repository issues, pull requests, discussions, review
threads, community spaces, and public situations where someone is representing
the project.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub
profile. Maintainers may edit or remove content, reject contributions, issue a
warning, temporarily restrict participation, or permanently ban a participant.
Reports will be handled as privately as practical.

This policy is adapted from the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
